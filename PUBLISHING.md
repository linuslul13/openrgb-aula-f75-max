# Preparing the first GitHub repository

Suggested repository name: `openrgb-aula-f75-max`.

1. Create a **private, empty repository** under your GitHub account at <https://github.com/new>, name `openrgb-aula-f75-max`, no autogenerated README, .gitignore or license (all are included here).
2. From inside this downloaded folder:

```bash
git init -b main
git add .
git commit -m "Initial OpenRGB AULA F75 MAX community driver"
git remote add origin git@github.com:YOUR_USERNAME/openrgb-aula-f75-max.git
git push -u origin main
```

Or, after the repo exists, let an authorized GitHub connector upload these files. Review the documentation and hardware tests before making the repository public or tagging `v0.2.0-rc1` as a prerelease.

The GitHub connector used to prepare these files can modify existing repositories, but cannot create a new repository. No changes have been made to any existing GitHub repository.
