# Attribution and protocol references

This original controller integration is SPDX `GPL-2.0-or-later` because it integrates with OpenRGB (GPL-2.0-or-later). It implements the receiver RGB packet format described by independent reverse-engineering efforts.

Relevant upstream research and code:

- <https://github.com/VitalyArt/Aula-F75-Max-Driver> (device reports and RGB setup; MIT-licensed project)
- <https://github.com/c0deJedi/aula-f75> (Linux command utility; protocol observations)
- <https://github.com/Ghost-CR/F75_Initializer> (packet reverse-engineering documentation)
- <https://gitlab.com/CalcProgrammer1/OpenRGB> (OpenRGB, GPL-2.0-or-later)

No third-party image, firmware, Windows binary, or logo is included. The driver is an independent community experiment.
